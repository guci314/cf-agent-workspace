# System One Models

一类**为"做出软件可直接使用的快速结构化决策"而构建的 AI 模型**。

命名借自 Daniel Kahneman《思考，快与慢》中的 System 1 —— 快速、直觉式判断。
与之相对的是 System 2（慢速、审慎推理）。当前各大推理模型（o3、Claude Thinking 等）
都在朝 System 2 狂奔；System One 模型走的是反方向。

## 核心机制

> 输入非结构化状态（state），输出类型化的答案 + 概率。

- 输出**不是文本**，而是类型安全的结构化值
- 可能输出的集合在调用前就已定义，因此**永不产生类型错误**
- 每个答案附带**校准过的**概率与置信度
- **并行采样**：单次查询生成全部输出，而非逐 token 自回归

## 与常规 LLM 的关键差异

| 维度 | 常规 LLM | System One 模型 |
|---|---|---|
| 输出 | 字符串，需解析+校验 | 类型安全结构化值 |
| 采样 | 顺序，逐 token | 并行，单次生成全部 |
| 置信度 | 过度自信、不一致 | 校准（置信度越高越准） |
| 幻觉 | 存在风险 | 结构上不可能 |
| 推理过程 | 可返回 | 不返回 |
| 文本生成 | 强项 | **完全不具备** |

## 代价

System One 模型**放弃了字符串生成能力**，因此：
- 不能聊天、写代码、写摘要
- 不能解释为什么这样判断
- 不能做工具调用循环（无法作为 agent 的主模型）

它的定位是**AI 工作流里的"智能 if 语句"**：分类、路由、打分、抽取、分支 ——
在硬编码逻辑太脆、而完整 LLM 调用太贵的地方。

## 适用判据

适合的决策有三个特征：
1. **重复、高频**
2. **可能答案在调用前已知**
3. 不需要生成式输出

## 代表实现

[[jev]]（TypeSafe AI）是第一个公开的 System One 模型。

## 在 agent 中的位置

System One 模型通常**不作为主模型**，而是：
- 作为 **tool/MCP server** 供主模型调用
- 或者嵌入代码，作为廉价的决策层

在 [[hermes-agent]] 这类运行时中，正确的接入方式是通过 MCP 暴露为工具，
而非塞进模型槽位。详见 [[jev-in-hermes]]。
